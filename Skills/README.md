# Skills do projeto

As seis pastas contêm skills autocontidas em português. Para usar, indique o caminho do SKILL.md correspondente na solicitação. Elas estão versionadas no projeto; esta entrega não altera o catálogo global do Codex nem afirma ativação automática.

- planejar-sistema-quantitativo: arquitetura e critérios de aceitação.
- implementar-ferramenta-quantitativa: backend, CLI e simulador.
- pesquisar-modelos-financeiros: dados e validação de modelos.
- planejar-testes-quantitativos: casos e resultados esperados.
- executar-testes-quantitativos: execução e diagnóstico.
- desenvolver-interface-financeira: frontend e visualização.
